# portfolio

Maia Swift's art director portfolio. Plain static HTML/CSS, ready for GitHub Pages
(Settings → Pages → deploy from `main`, root folder).

- `index.html` – homepage: intro header + one band per project
- `projects/*.html` – a page per project (stubs for now)
- `styles.css` – all styles
- `assets/` – header illustration and signature

Fonts (free, from Google Fonts): DM Mono (header and project text), Oswald 700 (project titles).
